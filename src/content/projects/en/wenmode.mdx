Wenmode is a Markdown toolkit for Python, built around explicit rule composition, mdast-compatible syntax trees, and pluggable renderers.

Parse Markdown once, then inspect, transform, or render the same tree. Presets provide CommonMark and GitHub-flavored Markdown rules, while custom rules let applications define their own dialect.

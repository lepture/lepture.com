Prosefly gives writers and developers a shared workspace for website content. Organize Markdown and MDX in Content Spaces, edit visually or in source, and collaborate in real time.

Drafts stay in the workspace until they're ready. Review the file changes, then publish a commit or pull request to GitHub. Your content remains in your own repository, and your existing build process updates the website.

A shared media library hosts images, audio, and video, which documents reference by URL.

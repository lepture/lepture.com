Prosefly 为作者与开发者提供共同维护网站内容的工作区。在内容空间中管理 Markdown 和 MDX，使用可视化或源码编辑器，并与团队实时协作。

草稿保存在工作区中，准备好后先审阅文件变更，再以 commit 或 pull request 发布到 GitHub。内容仍保存在你自己的仓库里，由网站原有的构建流程更新网站。

共享媒体库管理图片、音频和视频，文档通过 URL 引用这些资源。

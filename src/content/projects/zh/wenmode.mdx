Wenmode 是 Python 的 Markdown 工具集，围绕显式规则组合、兼容 mdast 的语法树和可替换的渲染器构建。

解析一次 Markdown，就可以检查、转换或渲染同一棵语法树。预设提供 CommonMark 和 GitHub 风格的 Markdown 规则，也可以通过自定义规则定义自己的语法。
